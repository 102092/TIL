## 3. 상세 설계

> 트랜스 코딩

- 단순 저장이 아니라, 다양한 해상도와 코텍드로 변환하고 잘게 쪼개는 과정이 필요함.
- 이 과정이 없으면 버퍼링이 발생할수 밖에 없음.
- 이 때문에 필요한 작업이 DAG(Directed Acyclic Graph) 모델 을 통한 작업 병렬 처리

## 4. 마무리
- API 서버는 무상태 -> 수평적 확장이 가능하다.
- 데이터베이스 다중화, 샤딩은 필수인듯.
- 비디오 업로드와 재생은 완전 다른 시스템
	- CQRS 관점
	- 하나의 서버에서 진행 시 원활한 서비스 제공이 어려워질 것
- 더 알아보면 좋은 것들
	- 비디오 인코딩 최적화 (Per-Title Encoding)
	- 지능형 캐싱 (Intelligent Caching)
	- 장애 격리 (Fault Isolation)
