## 3. 상세 설계

블록 저장소 서버
- 파일을 작은 블록 단위로 나누는 작업을 하는 서버
- 각 블록 마다 압축 알고리즘도 적용됨.
- 또한 파일이 수정되면 전체 파일 대신 수정이 일어난 블로만 동기화 함 (delta sync)

> 델타 동기화

![[Pasted image 20251223224131.png]]
- 파일을 작은 블록(예: 4MB)으로 분할
- 각 블록의 해시(SHA-256)를 계산
- 서버에 없는 블록(해시값 비교)만 전송
- **효과:** 100MB 파일에서 1KB만 수정해도 1KB 분량의 블록만 전송됨


높은 일관성 요구
- 관계형 데이터베이스(RDB) 사용 권장 (ACID 트랜잭션 보장)
-  메타데이터 캐시(Redis)와 DB 간의 정합성 유지 전략 필요
